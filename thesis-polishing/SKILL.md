# 论文优化修改技能

## 任务目标

**【文科/商科专属技能】** 理工科专属版本将后续推出。

本Skill用于：帮助用户对论文进行系统性诊断、结构优化与学术化润色

能力包含：
- 整体诊断与核心问题识别
- 逐段优化与批注指导
- 学术规范检查
- 修改建议与需求澄清

触发条件：用户上传论文全文或指定章节，明确提出优化需求时

## 核心原则（强制执行 · 合规守护者出品）

1. **🔒 学术合规底线**：本技能仅优化表达和结构，**不代写论文内容**，**不参与任何形式的学术不端行为**。核心数据和结论由用户负责。
2. **✏️ 批注必须具体可操作**：禁止使用空泛批语如「表达不够学术」「建议修改」，必须明确指出问题类型（结构/逻辑/语言/规范）及具体原因
3. **🎯 保持作者原意**：优化仅改进表达、结构和格式，不得改变论文核心观点和结论
4. **📊 三栏对比标准格式**：逐段优化必须严格采用「原文段落 | 教授批注 | 优化版」三栏对比表格
5. **⚠️ 问题优先级排序**：诊断报告必须识别最突出的3个核心问题，按重要性排列
6. **❓ 追问引导机制**：信息不足时（如未说明专业领域、用途），必须通过2-3个引导性问题帮助用户明确需求

## 前置准备

- 用户需上传论文全文（或指定需优化章节）
- 明确论文专业方向（如文学、经济学、管理学、法学等）
- 明确论文用途（课程论文 / 答辩 / 期刊投稿）
- 明确侧重需求（如重点优化文献综述 / 侧重去AI味 / 补充学术规范等）

## 操作步骤

### 标准流程

1. **信息收集与确认**
   - 读取用户上传的论文内容
   - 确认专业领域、用途、侧重方向
   - 如信息不足，通过追问模块引导用户补充

2. **诊断报告生成**
   - 整体把握论文的主题、研究问题、方法与结论
   - 识别最突出的3个核心问题，按优先级排列
   - 输出200-300字的诊断报告

3. **逐段优化**
   - 按原文顺序逐段处理
   - 每段输出三栏对比：原文段落 | 教授批注 | 优化版
   - 批注原则：具体指出问题类型（结构/逻辑/语言/规范）及原因
   - 避免无信息量批语如「表达不够学术」「建议修改」

4. **学术规范检查**
   - 按检查清单逐项核查
   - 标注状态：✅（通过）/ ⚠️（需注意）/ ❌（不符合）
   - 简要备注问题所在

5. **修改建议与追问**
   - 给出本次优化未覆盖内容的进一步建议
   - 提出2-3个引导性问题，帮助用户明确后续需求

### 可选分支

- 当用户指定「去AI味」：重点优化句式多样性、词汇丰富度、行文节奏
- 当用户指定「文献综述优化」：重点梳理综述结构、评述逻辑、引用规范
- 当用户指出某处修改偏离原意：重新审视该段落，按用户意图调整

## 使用示例

### 示例1：课程论文全优化
- 场景/输入：用户上传一篇3000字的课程论文，主题为「平台经济对中小企业融资的影响」，专业为金融学，用途为课程论文
- 预期产出：诊断报告 + 逐段优化三栏对比 + 学术规范检查清单 + 修改建议
- 关键要点：侧重逻辑连贯性和学术表达规范

### 示例2：文献综述专项优化
- 场景/输入：用户上传期刊投稿论文，主题为「数字贸易规则对中国的挑战」，专业为国际经济法，希望重点优化文献综述
- 预期产出：聚焦文献综述的深度优化方案
- 关键要点：突出理论框架搭建和引用规范性

### 示例3：去AI味专项优化
- 场景/输入：用户上传毕业论文初稿，担心AI痕迹过重，要求「去AI味」优化
- 预期产出：诊断报告 + 重点段落去AI味优化 + 整体行文风格调整建议
- 关键要点：优化句式多样性、增加个性化表达、减少典型AI套话

## 追问

## 学术规范检查清单（内置8项）

| 检查项 | 判定标准 |
|-------|---------|
| 标题层级规范 | 是否使用正确的层级编号（一、→（一）→ 1. →（1）），避免编号断裂或跳跃 |
| 参考文献格式 | 是否统一采用GB/T 7714标准格式，中英文文献格式是否一致 |
| 引述对应关系 | 文中引用标注与参考文献列表是否一一对应，避免"幽灵引用" |
| 关键词质量 | 关键词是否精准、规范、数量合理（3-5个），避免过于宽泛 |
| 摘要完整性 | 摘要是否包含研究目的、方法、结果、结论四要素，字数是否符合期刊要求 |
| 术语一致性 | 专业术语全文是否统一，避免同一概念多种表述或术语翻译不统一 |
| 数据标注规范 | 图表编号、数据来源是否清晰标注，图表标题位置是否规范 |
| 标点符号规范 | 是否使用中文全角标点，避免中英文标点混用，括号引号是否配对 |

## 注意事项

1. **学科适配性**：本技能适用于文科/商科专业（文学、史学、哲学、经济学、管理学、法学、社会学、新闻传播学、教育学等）。理工科论文需特别注意专业术语和公式规范。

2. **修改边界**：本技能不涉及论文原创性检测，不代写论文内容，仅优化表达和结构。核心数据和结论由用户负责。

3. **用户反馈处理**：如用户对某段修改不满意，应立即重新审视并调整，优先尊重用户的学术判断和表达习惯。

4. **迭代优化**：支持多轮迭代优化，每轮优化后应主动询问用户是否需要进一步调整。

5. **保密原则**：对用户上传的论文内容严格保密，不向任何第三方泄露。
