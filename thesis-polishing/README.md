# 📝 论文优化修改技能 (thesis-polishing)

**合规守护者出品** — **【文科/商科专属】** 专业的论文结构诊断与学术化优化工具，坚守学术诚信底线，帮助您完成课程论文、答辩PPT或期刊投稿前的全文优化润色。

> ℹ️ 理工科专属版本将后续推出

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| 🩺 **整体诊断** | 识别论文最突出的3个核心问题，输出专业诊断报告（200-300字） |
| 📝 **逐段优化** | 三栏对比呈现：原文段落 | 教授批注 | 优化版文本，批注必须具体可操作 |
| ✅ **学术规范检查** | 8项标准核查：标题层级、参考文献格式、术语一致性、数据标注等 |
| 🤖 **去AI味专项优化** | 检测并去除典型AI痕迹，提升句式多样性和自然度 |
| 🔍 **文献综述优化** | 专项梳理综述结构、评述逻辑、引用规范 |
| 💡 **修改建议** | 提供专业方向的后续优化建议和追问引导 |
| 📋 **结构化输出** | 标准化输出模板，确保每次优化质量一致 |

## 🎯 输出示例

```
# 一、诊断报告
论文整体结构清晰，但存在三点核心问题：
1. 标题层级编号混乱（二级标题混用两种格式）
2. 部分段落口语化表达明显（如"躺赢时代正在结束"）
3. 参考文献格式不统一

# 二、逐段优化
| 原文段落 | 教授批注 | 优化版 |
|---------|---------|-------|
| 泡泡玛特的"躺赢时代"正在结束 | 🔴 口语化表达，学术写作应使用更客观的表述 | 泡泡玛特的高速增长态势已有所放缓 |

# 三、学术规范检查清单
| 检查项 | 状态 | 备注 |
|-------|------|------|
| 标题层级规范 | ⚠️ | 二级标题编号格式不统一 |
| 参考文献格式 | ⚠️ | 中英文文献格式不一致 |
| 术语一致性 | ✅ | 术语使用统一 |

# 四、修改建议与追问
## 修改建议
1. 建议全文统一标题编号格式为"一、→（一）→ 1. →（1）"
2. 建议对照GB/T 7714-2015标准统一参考文献格式

## 追问
❓ 是否需要我帮你全文统一标题编号格式？
❓ 参考文献格式需要调整为哪个标准？（GB/T 7714/APA/MLA）
```

## 🔬 学术规范检查清单（内置8项）

| 检查项 | 判定标准 |
|-------|---------|
| 标题层级规范 | 是否使用正确的层级编号 |
| 参考文献格式 | 是否统一采用GB/T 7714标准 |
| 引述对应关系 | 文中引用与参考文献是否一一对应 |
| 关键词质量 | 关键词是否精准规范（3-5个） |
| 摘要完整性 | 是否包含研究目的、方法、结果、结论四要素 |
| 术语一致性 | 专业术语全文是否统一 |
| 数据标注规范 | 图表编号、数据来源是否清晰标注 |
| 标点符号规范 | 是否避免中英文标点混用 |
